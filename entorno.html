Herramientas y funcionamiento de la web

¿Qué ocurre al escribir una URL?

Cuando escribo una dirección web en el navegador, primero se busca la dirección IP del servidor mediante el sistema DNS. Después, el navegador se conecta al servidor y solicita la página utilizando HTTP o HTTPS.

El servidor recibe la petición y devuelve una respuesta con los archivos necesarios. Finalmente, el navegador interpreta el HTML, el CSS y el JavaScript para mostrar la página web.

  1. Escribo la URL en el navegador.
  2. Se obtiene la dirección IP mediante DNS.
  3. El navegador se conecta al servidor.
  4. El servidor responde a la petición.
  5. El navegador muestra la página.

Herramientas que utilizo

Visual Studio Code

Lo utilizo para escribir y organizar el código de mis páginas web.

Extensiones

Añaden funciones al editor, como ayudas para escribir código, detectar errores o trabajar con distintos lenguajes.

Live Server

Permite abrir la página en el navegador mediante un servidor local y ver los cambios mientras trabajo.

Git y GitHub

Git sirve para guardar versiones de los archivos y registrar los cambios mediante commits. GitHub permite subir el repositorio a Internet y compartirlo con otras personas.
